# USRP_Assistant
For novices, it is very important to get the device running quickly. We have built a usrp assistant tool to perform self-check, driver installation, benchmarking and other functions of the usrp device.

# Version
## 0.0.1
- With B series driver installation function
- Ability to choose different uhd versions
